# Model Artifacts Directory

This directory stores verified model artifacts and metadata generated by `scripts/train_model.py` and the `/api/model/train` endpoint:

- `model.joblib`: The primary trained and calibrated classifier.
- `xgb_raw.joblib`: Uncalibrated native XGBoost model for SHAP tree explanations.
- `baselines.joblib`: Serialized baseline comparison models (Logistic Regression, Random Forest, URL-Only XGBoost, Scaler).
- `feature_schema.json`: Formal versioned schema of the 52 extracted features and descriptions.
- `metadata.json`: Model version, training timestamp, hyperparameters, thresholds, sample counts, and dataset fingerprint.
- `evaluation.json`: Comprehensive empirical performance benchmark on unseen registered domains, confusion matrix, ROC/PR curves, and generalization comparison.
